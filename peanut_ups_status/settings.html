🔋 PeaNUT UPS status

Monitor your UPS status from a PeaNUT device API endpoint.

Connect a PeaNUT UPS device, choose a display heading, and select the battery, runtime, load, and voltage measurements shown on your e-paper display.

🔗

Find the device endpoint

Enter the full PeaNUT API URL for a specific UPS device, such as http://peanut-host.local:8080/api/v1/devices/cyberups. The InkyPi host must be able to reach it.

🔌

Connection and heading

Point the plugin at your UPS device and name the display.

Use the full device API endpoint, not only the PeaNUT server’s base URL.

Optional. Leave blank to use the default UPS Status heading.

📊

Display options

Choose which UPS details appear on the rendered display.
Battery

Show the battery charge percentage.

Runtime

Show estimated remaining runtime.

Load

Show current UPS load percentage.

Input voltage

Show the current incoming line voltage.

Output voltage

Show the current UPS output voltage.

Battery voltage

Show the current battery voltage.
